Common Mistakes - Interview Tips - Pattern Recognition# Graph Traversal (DFS & BFS) 🚀

Graph traversal means **visiting every vertex (node)** of a graph.

There are two ways:

1. DFS (Depth First Search)
2. BFS (Breadth First Search)

---

# Graph Representation (Adjacency List)

Suppose we have the following graph.

```
        0
      /   \
     1     2
    / \
   3   4
```

Adjacency List

```cpp
adj[0] = {1,2}
adj[1] = {0,3,4}
adj[2] = {0}
adj[3] = {1}
adj[4] = {1}
```

---

# DFS (Depth First Search)

## Idea

DFS goes **as deep as possible** before coming back.

Think of it like exploring a maze.

```
0
|
v
1
|
v
3

Backtrack

1
|
v
4

Backtrack

0
|
v
2
```

DFS uses

- Recursion
- Stack (internally)

---

# DFS Algorithm

```
Visit node

Mark visited

Visit all unvisited neighbours

Return (Backtrack)
```

---

# DFS Flow

Starting node = 0

```
DFS(0)

Visit 0

↓

Visit 1

↓

Visit 3

↓

No neighbour

Backtrack

↓

Visit 4

↓

No neighbour

Backtrack

↓

Visit 2

↓

Finish
```

Traversal

```
0 → 1 → 3 → 4 → 2
```

---

# DFS Template

```cpp
void dfs(int node, vector<vector<int>>& adj, vector<bool>& visited)
{
    visited[node] = true;

    cout << node << " ";

    for(int neighbour : adj[node])
    {
        if(!visited[neighbour])
        {
            dfs(neighbour, adj, visited);
        }
    }
}
```

Call

```cpp
vector<bool> visited(V,false);

dfs(0,adj,visited);
```

---

# Complete DFS Code

```cpp
#include<iostream>
#include<vector>
using namespace std;

void dfs(int node, vector<vector<int>>& adj, vector<bool>& visited)
{
    visited[node]=true;

    cout<<node<<" ";

    for(int neighbour : adj[node])
    {
        if(!visited[neighbour])
        {
            dfs(neighbour,adj,visited);
        }
    }
}

int main()
{
    int V=5;

    vector<vector<int>> adj(V);

    adj[0]={1,2};
    adj[1]={0,3,4};
    adj[2]={0};
    adj[3]={1};
    adj[4]={1};

    vector<bool> visited(V,false);

    dfs(0,adj,visited);
}
```

# BFS (Breadth First Search)

## Idea

BFS visits nodes **Level by Level**.

Instead of going deep,

it visits every neighbour first.

BFS uses

- Queue

# BFS Template

```cpp
void bfs(int start, vector<vector<int>>& adj, vector<bool>& visited)
{
    queue<int> q;

    q.push(start);

    visited[start]=true;

    while(!q.empty())
    {
        int node=q.front();

        q.pop();

        cout<<node<<" ";

        for(int neighbour : adj[node])
        {
            if(!visited[neighbour])
            {
                visited[neighbour]=true;

                q.push(neighbour);
            }
        }
    }
}
```

Call

```cpp
vector<bool> visited(V,false);

bfs(0,adj,visited);
```

# Complete BFS Code

```cpp

                q.push(neighbour);
            }
        }
    }
}

int main()
{
    int V=5;

    adj[0]={1,2};
    adj[1]={0,3,4};
    adj[2]={0};
    adj[3]={1};
```

# Disconnected Graph

Suppose graph is

```
0 ---- 1 ---- 2


3 ---- 4
```

Calling

```cpp
dfs(0)
```

will visit only

```
0 1 2
```

because

```
3

and

4

are disconnected.
```

So we do

```cpp
vector<bool> visited(V,false);

for(int i=0;i<V;i++)
{
    if(!visited[i])
    {
        dfs(i,adj,visited);
    }
}
```

Similarly for BFS

```cpp
vector<bool> visited(V,false);

for(int i=0;i<V;i++)
{
    if(!visited[i])
    {
        bfs(i,adj,visited);
    }
}
```

This ensures every component is visited.

---

# Time Complexity

DFS

```
O(V+E)
```

Why?

Every vertex is visited once.

Every edge is explored once.

---

BFS

```
O(V+E)
```

Same reason.

---

# Space Complexity

DFS

```
Visited Array

+

Recursion Stack

=

O(V)
```

BFS

```
Visited Array

+

Queue

=

O(V)
```

---

# DFS vs BFS

| DFS | BFS |
|------|------|
| Uses Recursion / Stack | Uses Queue |
| Goes Deep First | Goes Level by Level |
| Traversal Example | 0 1 3 4 2 |
| Traversal Example | 0 1 2 3 4 |
| Time O(V+E) | Time O(V+E) |
| Space O(V) | Space O(V) |

Graph traversal means **visiting every vertex (node)** of a graph.

There are two ways:

1. DFS (Depth First Search)
2. BFS (Breadth First Search)

# Graph Representation (Adjacency List)

```
      /   \
     1     2
    / \
   3   4
```

Adjacency List

# DFS (Depth First Search)

## Idea

DFS goes **as deep as possible** before coming back.

Think of it like exploring a maze.

```
0
|
v
1
|
v
3

Backtrack

1
|
v
4

Backtrack

0
|
v
2
```

DFS uses

- Recursion
- Stack (internally)

---

# DFS Algorithm

```
Visit node

Mark visited

Visit all unvisited neighbours

Return (Backtrack)
```

---

# DFS Flow

Starting node = 0

```
DFS(0)

Visit 0

↓

Visit 1

↓

Visit 3

↓

No neighbour

Backtrack

↓

Visit 4

↓

No neighbour

Backtrack

↓

Visit 2

↓

Finish
```

Traversal

```
0 → 1 → 3 → 4 → 2
```

---

Graph

```
adj[0] = {1,2}
```

# DFS Template

```cpp
void dfs(int node, vector<vector<int>>& adj, vector<bool>& visited)

    visited[node] = true;

    cout << node << " ";

    for(int neighbour : adj[node])
    {
        if(!visited[neighbour])

}
```

# BFS (Breadth First Search)

## Idea

BFS visits nodes **Level by Level**.

Instead of going deep,

it visits every neighbour first.

BFS uses

- Queue

---

# BFS Flow

```
        0
      /   \
     1     2
    / \
   3   4
```

Traversal

```
Level 0

0

↓

Level 1

1 2

↓

Level 2

3 4
```

Output

```
0 1 2 3 4
```

---

# BFS Algorithm

```
Push starting node

Mark visited

While queue not empty

Take front node

Visit it

Push all unvisited neighbours
```

```

```

```
Queue
```

```
Empty
```

# BFS Template

```cpp
void bfs(int start, vector<vector<int>>& adj, vector<bool>& visited)
{
    queue<int> q;

    q.push(start);

    visited[start]=true;

    while(!q.empty())
    {
        int node=q.front();

        q.pop();

        cout<<node<<" ";

        for(int neighbour : adj[node])
        {
            if(!visited[neighbour])
            {
                visited[neighbour]=true;

                q.push(neighbour);
            }
        }
    }
}
```

Call

```cpp

bfs(0,adj,visited);
```

# Disconnected Graph

Suppose graph is

```
0 ---- 1 ---- 2


3 ---- 4
```

Calling

```cpp
dfs(0)
```

will visit only

```
0 1 2
```

because

```
3

and

4

are disconnected.
```

So we do

```cpp
vector<bool> visited(V,false);

for(int i=0;i<V;i++)
{
    if(!visited[i])
    {
        dfs(i,adj,visited);
    }
}
```

Similarly for BFS

```cpp
vector<bool> visited(V,false);

for(int i=0;i<V;i++)
{
    if(!visited[i])
    {
        bfs(i,adj,visited);
    }
}
```

This ensures every component is visited.
